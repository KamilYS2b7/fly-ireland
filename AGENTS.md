# Visual changes and previews

For changes to wind roses, cloud-height labels, map point icons or their controls,
render a local preview and show it to the user before publishing a new version to
Windy. Use the actual plugin markup/styles where practical and label simulated
map backgrounds and sample forecast data clearly. Obtain layout feedback before
Windy publication rather than uploading a new release solely to preview it.

Keep map point coordinates unchanged for layout work. Do not publish to Windy
automatically unless the user explicitly requests it. GitHub updates may be
pushed when the user authorizes implementation, following preview review.
