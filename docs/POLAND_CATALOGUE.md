# Preserved Polish catalogue

Polish locations and country selection are temporarily disabled in the published interface. All catalogue records, owner approvals, videos, guides and review files remain in the source.

To restore the country option and activate the catalogue, set `POLAND_ENABLED = true` in `src/siteFilters.ts`, then run the tests and rebuild.

- Polish map import: 66 added records and videos for 25 existing sites, compared by name, launch context, coordinates and video identity. The import links 114 distinct checked YouTube videos across 85 sites. The owner approved all 117 current site/video associations on 26 October 2026; these remain accepted independently of browser storage. Future undecided films can use **Videos to review** and **Accept / Reject**. Shared films preserve each site's chapter offset. **With YouTube videos** filters both cards and markers.

- Polish direction review: purple question badges identify the 34 remaining sites with unverified sectors. **Wind ranges to review** isolates remaining entries; **Set wind range** / **Edit saved wind range** opens a map-adjacent editor and brings the large rose into view. Typing previews multiple sectors and north-crossing ranges on that rose without changing forecast matching. **Confirm & save** stores each checkpoint in the browser and updates the connected JSON file. Choose/reconnect the same review file after reloading, or use **Download JSON** / **Load JSON**. Imported file data merges drafts and confirmations independently, retaining the latest accepted range even when a newer draft exists. These are review records for a later catalogue import. See the [Polish review instructions](POLAND_WIND_REVIEW.pl.md).

Poland has 62 sites with explicit wind limits: 14 source-documented and 48 owner-confirmed. The remaining 34 sites (two original guide sites and 32 map additions) await direction verification. The owner import is recorded in [the import report](../reports/poland-owner-wind-import-2026-10-26.md). Forecast-enabled records retain weather readings without entering **Wind-matched** when their direction limits are unknown. Preferred compass bearings are not expanded into invented tolerances. The eight Prowing cards are brief references. Approximate positions retain verification labels. Skrzyczne uses the east face and current Lipowa landings; Kaimówka is not mapped as an active landing. Source links are available in the Polish guides and research reports.

The owner confirmed the **Just / Jezioro Rożnowskie** take-off at **49.722607, 20.645784** on 26 October 2026, replacing the list's lake reference. It now uses a normal forecast rose with the owner-confirmed 120°–160° wind range. The other map additions retain their source positions with verification notes and no invented guides or wind limits. Two Irish pins and Czech Slamník were excluded from the Poland import.
